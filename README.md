# 📰 Editorial Portfolio Website

A personal, responsive, editorial-style portfolio website designed with a classic newspaper/print aesthetic. Built using pure **HTML5** and **CSS3**, this site showcases software development projects, technical skills, and contact links.

---

## ✨ Features

- **Editorial & Print Aesthetic**: Unique typography, bold brutalist layout, and high-contrast color scheme (`#CDC6BE` cream background & `#060504` ink black text).
- **Fully Responsive**: Adapts seamlessly across desktop, laptop, tablet, and mobile displays using CSS Flexbox and fluid `clamp()` sizing.
- **Projects Showcase**: Sectioned display featuring desktop applications, AI agents, machine learning models, and full-stack web applications.
- **Pure HTML & CSS**: Lightweight, dependency-free design with fast load times (uses FontAwesome for icons).

---

## 🛠️ Built With

* **HTML5**: Semantic structure and structure markup.
* **CSS3**: Custom layout using Flexbox, media queries, and fluid typography.
* **FontAwesome (v6.7.2)**: Social and section iconography.

## 💻 Getting Started Locally

To run this website locally on your computer:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/chirag982/portfolio.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd portfolio
   ```

3. **Open `index.html` in your browser:**
   - Double-click `index.html` in your file explorer, OR
   - Use a local server extension such as VS Code's **Live Server**.
